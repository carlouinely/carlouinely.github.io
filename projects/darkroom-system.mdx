## Why a darkroom in the browser

Film photographers do the hard part in the physical world: exposing, developing,
sleeving. Then the scan lands on a disk and the thread gets lost. The negative is
an object with a history; the file beside it is usually an anonymous
`IMG_0421.tif`. **Darkroom System** puts the two back together.

> Density readings stay attached to the frame that produced them, so you can
> reproduce a grade months later instead of retyping it from a paper log.

### What it does

- Reads roll and frame metadata from the negative sleeve
- Keeps a per-frame exposure log beside the scan it describes
- Exports a contact sheet and a per-roll `csv` for the lab notebook

### How it is built

The catalogue is a small Postgres schema: a roll has frames, a frame has
readings, and a reading has a developer, a dilution, and a time. The interface is
React over a typed query layer, so a grade's shape is the data's shape instead of
a pile of form state.
