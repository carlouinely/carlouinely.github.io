## One dashboard for every screen

University announcements used to be updated one display at a time. **WILDFIRE**
is a centralized digital signage platform that publishes to every screen from a
single dashboard.

Screens run on Raspberry Pi devices attached to ordinary monitors, so a campus
can reuse the hardware it already owns. The dashboard publishes text, images,
video, and PDFs, schedules content per screen or per group, onboards a new screen
by link, and monitors the fleet's health remotely. A campus-wide emergency
override can interrupt every screen at once.
